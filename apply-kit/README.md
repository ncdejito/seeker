# Apply Kit

Local-first CV tailoring + application tracker for Filipino job seekers (EU, Spain, Australia, remote).

**Open `index.html` in a browser.** No account, no install, nothing is uploaded.

1. Click **Load a 2-minute sample**, or paste your own CV and pick a role/destination.
2. Paste a job ad. Score keywords, then **Copy prompt** into ChatGPT, Claude, or Gemini.
3. Save applications in the tracker. **Export CSV** to share with a helper.

Visa links in the page go to official government sites. Verify there — this is not legal advice.

See the repo README section **MVP option B: how to use and share**.
